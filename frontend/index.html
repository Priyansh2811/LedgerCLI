Financial tracking engineered for the terminal.

Eliminate bloated spreadsheet tabs. Log transactions via natural language in under 400ms, set hard category constraints, and query balances without ever leaving your shell.

curl -sSL ledgercli.dev/install.sh | bash
bash — 80x24

$ tracker quick "450 for team lunch via upi"

$ tracker budget set -c Lunch -l 3000

Built with strict systems principles

Local SQLite Storage

All transaction histories reside solely in your home directory at ~/.ledgercli.db. No unencrypted cloud relays, no latency.

Fast Natural Parsing

Sub-millisecond regex tokenization extracts amount, merchant, and method (UPI, Card, Cash) without dialing remote LLM APIs.

Budget Threshold Alerts

Real-time delta checks run on every insert, displaying caution banners at 80% usage and hard stops when category ceilings are exceeded.

Frequently Asked Questions

Where is my transaction and balance data stored? +

Your records are stored locally in an embedded SQLite database at ~/.ledgercli.db on your system drive. No financial records ever touch remote networks unless you deliberately run custom export flags.

How does the natural language parser process quick inputs? +

The parser utilizes an internal deterministic regex engine that extracts currency amounts, normalizes descriptors, and detects payment channels (UPI, Card, Cash) offline in less than 2 milliseconds.

Can I export data for accounting or tax reporting? +

Yes. Run tracker export -o expenses.csv to output clean, comma-separated rows fully compliant with Microsoft Excel, Apple Numbers, and Google Sheets.

Does this require administrative privileges or network access? +

No. The binary runs entirely within standard user permissions and functions with zero network dependencies. It works completely offline during flights or disconnected sessions.

Which operating systems and shells are supported? +

LedgerCLI compiles as a standalone executable across macOS (Intel and Apple Silicon), Linux (x86_64, arm64), and Windows (via PowerShell, CMD, or WSL2).
